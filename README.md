## About

This repository contains the reference implementation of **TEGAT**, a graph
attention model that predicts **transmission risk** among confirmed COVID-19 cases
using the heterogeneous event network extracted from publicly released Chinese
epidemiological investigation texts.

The pipeline processes 4,812 confirmed cases across 30 Chinese provinces (489-day
window from 2019-08-30 to 2020-12-31), constructs a 5-node-type heterogeneous event
graph (case, venue, date, transport, symptom), and trains a multi-head temporal graph
attention network with five random seeds.

## Quick start

### 1. Clone & install

```bash
git clone https://github.com/RockyZhang1122/TEGAT.git
cd TEGAT
pip install -r requirements.txt
```

### 2. Reproduce the headline numbers

```bash
python reproduce.py
```

This single command will:

1. Skip event extraction (bundled `data/events_extracted.json` is the same byte stream as the freshly extracted one).
2. Skip graph construction (bundled `data/graph_data.npz` matches the built graph).
3. Compute dataset statistics.
4. Train TEGAT and all baselines across five seeds.
5. Run the component-ablation suite.
6. Run RQ1 (venue risk), RQ2/RQ3 (asymptomatic + lockdown), RQ3 (causal).
7. Re-emit the LaTeX tables that go into `paper/`.

Results land in `results/` as JSON + Markdown. LaTeX tables land in
`results/latex_tables.txt` and `results/ablation_latex_tables.txt`.

For a quick sanity check (1 seed, ~5 minutes on a single core):

```bash
python reproduce.py --fast
```

To skip parts of the pipeline:

```bash
python reproduce.py --skip extract graph rq3
```

## Reproducibility notes

- All randomness is seeded; the paper reports mean ± std across seeds
  `{42, 123, 456, 789, 1024}`.
- Determinism: the NumPy and scikit-learn paths are deterministic given the same
  seed and BLAS implementation. PyTorch is not used.
- The shipped `results/*.json` files were produced on 2024-09-04 with
  `numpy=1.24`, `scikit-learn=1.3`, `xgboost=1.7`, `networkx=3.0`.
- For accuracy to the published digits, run on the same versions.
